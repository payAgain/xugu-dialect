# P-005 纳入 Demo Boot 自动化冒烟

## Goal
将 **Demo 用户冒烟** 纳入生产回归基线：在 `demo-spring-boot` 增加可自动化、可门控的 live 冒烟（`@SpringBootTest` + 真库 **或** 经 Scope 认可的等价脚本），与现有 offline smoke 并存。

## Baseline requirement (Scope)
- 默认 `mvn test` 仍可跳过 live（offline smoke 保持绿）
- `XUGU_RUN_IT=true` 全量基线必须包含 Demo 路径

## Out of scope
- Demo 业务功能扩展
- Ship

## Acceptance
**Condition:** SSOT 含 demo entry；offline + gated live 均文档化。  
**Action:** 门控下 Demo 模块测试 PASS。  
**Result:** 冒烟类/脚本路径写入 `contracts/production-regression-baseline.md`。
