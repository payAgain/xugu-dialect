# P-002 修复序列元数据 getQuerySequencesString

## Goal
修复 `hbm2ddl.auto=validate` 报 `missing sequence`（P1）：实现 `getQuerySequencesString()`（及必要 extractor），使方言能从虚谷 `all_sequences`（或等价目录）读取序列元数据；本仓补充门控真实库 IT 并 VERIFY PASS。版本保持 **7.4.5.Final**。

## Allowed paths
- `dialect/src/main/java/**`（`getQuerySequencesString`、序列信息 extractor / 相关 Dialect 钩子）
- `dialect/src/test/java/**`（sequence metadata / schema validate IT）
- `contracts/feature-matrix-definition-a.md`、`contracts/xugu-dialect.contract.md`（仅本 Phase 相关勾选/勘误）

- 官方 content 写入；扩大定义 A 范围

## Impact analysis
- Interfaces / callers: SchemaManagement / validate；依赖序列生成器的实体
- Data / migration: 只读元数据查询；不破坏现有序列对象
- Security / privacy: 无新密钥面
- Reliability / failure recovery: 元数据 SQL 失败须可诊断；缺序列时 validate 行为符合 Hibernate 预期
- Performance / capacity: 目录查询量通常小；注明若有全库扫描代价
- Deployment / configuration / rollback: 同 GAV 行为修复
- Explicitly unaffected surfaces: HQL 分页（P-001）、demo 业务逻辑、Ship
