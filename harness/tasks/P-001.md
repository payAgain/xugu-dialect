# P-001 DROP SEQUENCE IF EXISTS（AUTO / create-drop）

## Goal
`XuguSequenceSupport` 对 DROP 发出幂等 SQL（`drop sequence if exists …`），使 Hibernate 7 `GenerationType.AUTO` → 物理序列 + Schema create-drop / `halt_on_error` 不再因缺序列 E7002 失败。

## Acceptance
- Given live XuguDB and an entity with `GenerationType.AUTO` (non-UUID), when SessionFactory builds with create-drop (or equivalent schema drop of the auto sequence when absent), then no E7002 halt; ORM IT PASS; unit asserts drop string contains `if exists`.

## Out of scope
- JDBC 驱动修改；IDENTITY/保留字（P-002）；Ship；升版本
