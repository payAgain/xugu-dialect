# P-001 脚手架 Maven 多模块与验证契约

## Goal
落地父 POM + `dialect/` + `demo-spring-boot/` 最小可构建骨架；以 `systemPath`（或等价）接入仓库根 `xugu-jdbc-12.3.6.jar`；将 `harness/verification.json` 与 `AGENTS.md` 中的 build/test 占位符替换为真实 `mvn` 命令，使后续 Phase 具备可执行验证基线。

## Allowed paths
- 根 `pom.xml`（若新建）
- `dialect/**`（骨架：pom、空/最小源码与测试目录）
- `demo-spring-boot/**`（骨架：pom、最小 Spring Boot 入口占位，**不**实现业务演示）
- `harness/verification.json`
- `AGENTS.md`（仅 Real commands 占位符替换）
- `docs/architecture.md`（状态从 Planned → scaffolded 的事实更新）
- `harness/ownership/OWNERSHIP.yaml`（模块已存在后的 notes 刷新）
- `harness/evidence/**/P-001/**`
- `harness/handoffs/**/P-001.*`

## Forbidden paths
- 定义 A 方言能力实现（类型/DDL/分页等）
- 完整 Spring Boot 演示业务与 `docs/user-guide/` 正文
- 阅读或移植 `E:\Work\java\hibernate-dialect`
- 继承 `MySQLDialect` / `OracleDialect`
- `E:\Work\docs\content` 写入
- 未经 Human Gate 的 `tag` / `push` / Central 发布

## Impact analysis
- Interfaces / callers: 引入 Maven 坐标 `com.xugu:xugu-dialect:7.4.5.Final` 与 demo 模块依赖边；对外尚无稳定公共 API 实现
- Data / migration: 无
- Security / privacy: JDBC 依赖指向本地 jar；不得提交生产密钥
- Reliability / failure recovery: 无运行时服务变更
- Performance / capacity: 无
- Deployment / configuration / rollback: 可本地 `mvn -q -DskipTests package` / `mvn test`（精确命令写入 verification.json）；回滚=丢弃本 Phase 提交
- Explicitly unaffected surfaces: Dialect SQL 生成、SPI 自动识别、user-guide 内容、定义 A 矩阵正文
