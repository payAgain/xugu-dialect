# P-003 添加文档不允许与延后负向断言

## Goal
为矩阵中 **文档不允许** 与 **延后** 行建立基线负向断言：明确不支持、不发明 SQL、或 defer 标记；纳入 SSOT 与默认/门控测试套件。

## Scope rows (minimum)
- Definition A：7×文档不允许 + 20×延后（含 A-XCUT-010/011 永久禁止）
- I-003 C-*：2×文档不允许 + 5×延后
- 负向形式：Dialect flag=false、SQL 不含 forbidden 关键字、或 `@Disabled`+SSOT 条目（延后）

## Out of scope
- 将延后行提升为可实现
- Bulk insert 决策（P-004）

## Acceptance
**Condition:** SSOT 中所有 non-可实现行有 `negative-only` 或 `deferred-documented` 条目。  
**Action:** 单元/门控 IT 运行；断言失败即回归。  
**Result:** 负向测试清单 + SSOT 更新；reviewer PASS。
